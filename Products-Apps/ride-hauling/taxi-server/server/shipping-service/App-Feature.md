# 📦 App-Feature: Shipping Service

The Shipping Service handles large-scale logistics and external carrier integrations.

## 核心功能 (Core Features)

### 1. 🏗️ Carrier Factory
- **Unified Interface**: A single API to interact with multiple carriers (DHL, FedEx, GIG Logistics).
- **Rate Comparison**: Real-time price fetching from different logistics providers.

### 2. 🛰️ Global Tracking
- **State Normalization**: Translates disparate carrier statuses (e.g., "In Transit", "On Wheels") into unified system states.
- **Audit Logs**: Maintains a full history of package movement.

### 3. 🖼️ Multi-Modal Logistics
- **Photo Proof**: Supports image uploads for package verification at pickup/delivery.
- **Weight & Fragility**: Detailed package metadata management for safe transit.
