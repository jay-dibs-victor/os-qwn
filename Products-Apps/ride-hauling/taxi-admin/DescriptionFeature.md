# Admin Dashboard (Fleet Observatory)

## The Idea
The Admin Dashboard serves as the central command-and-control center for Queens operators and fleet managers. It provides a comprehensive, bird's-eye view of the entire logistics ecosystem, allowing for real-time monitoring, intervention, and strategic decision-making.

## Business Model Contribution
- **Enterprise SaaS Offering:** This dashboard can be whitelabeled or offered as a B2B service for logistics companies to manage their own independent fleets.
- **Risk Mitigation & Support:** Provides customer support agents with the tools to resolve disputes, trace lost items, and override system errors, minimizing financial liabilities.
- **Data-Driven Optimization:** Financial analytics and task density heatmaps help operators identify lucrative zones and optimize pricing models (surge pricing).

## Core Features
- **Live Fleet Visualization:** A real-time map displaying all active vehicles, with distinct markers for scooters, sedans, and freight vehicles.
- **Logistics Performance HUD:** Centralized metrics tracking courier task density, success rates, SLA compliance, and fleet health.
- **Force Assign & Manual Override:** Administrative controls to manually dispatch a driver, re-route a trip, or cancel anomalous bookings in emergency scenarios.
- **User & Driver Management:** Interfaces for vetting new drivers, suspending accounts, reviewing user feedback, and managing onboarding documentation.
- **Financial Auditing:** Detailed ledger views of all transactions, commission calculations, and payout schedules.
