# Queens Frontend - Feature Inventory (Enterprise Edition)

The Queens User Application is a premium, high-fidelity platform designed for seamless logistics and passenger safety.

## 🚀 Core Booking & Navigation
- **Advanced Booking Wizard**: Support for both instant "Quick Rides" and scheduled "Planned Rides" using Google Directions API.
- **Real-Time Map Engine**: High-frequency location updates with smooth polyline tracing and driver telemetry.
- **Navigation HUD**: Floating glassmorphic HUD displaying next-turn maneuvers (arrows) and real-time distance countdowns.
- **Turn-by-Turn Voice Nav**: Professional spoken instructions (Web Speech API) for hands-free navigation updates.

## 💎 Personalized Experience
- **One-Tap Saved Places**: Instant booking buttons for "Home" and "Work" destinations mapped to user preferences.
- **Smart Search History**: Persistent local cache of the most frequent destinations for rapid selection.
- **Identity Hub**: High-fidelity profile management featuring digital identity cards, referral codes, and security controls.

## 🗣️ Communication & Feedback
- **Live Ride Chat**: Persistent, real-time messaging between passenger and driver with typing indicators.
- **Voice-Over Call UI**: Premium signaling interface for voice calls with animated audio ripples and active call state management.
- **Premium Rating System**: Post-trip feedback loop with 5-star ratings and specific "Compliment Tags" (e.g., *Clean Car*, *Great Music*).

## 🛡️ Safety & Wallet
- **Emergency SOS Hub**: One-tap security reporting with automated live-location sharing.
- **Safety Circle**: Management of "Trusted Contacts" for automatic notification during active rides.
- **Digital Wallet**: Real-time balance tracking, transaction ledger, and integrated payment gateways (Paystack).
- **Proactive Alerts**: Visual and audio warnings for unexpected stops or route deviations.

---
*Built with React, Zustand, Framer Motion, and Google Maps API.*
