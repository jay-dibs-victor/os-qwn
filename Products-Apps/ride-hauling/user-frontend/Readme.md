# Queens User Application

A premium, high-fidelity passenger booking application designed for a seamless, enterprise-grade ride-hailing experience.

## ✨ Premium Features

### 1. Modern Glassmorphic UI
- **Futuristic Dashboard**: Real-time map integration, wallet overview, and quick-action grid.
- **Dynamic Animations**: Powered by Framer Motion for smooth transitions and interactive feedback.
- **Visual Feedback**: Real-time ride status indicators and glassmorphic modal systems.

### 2. Intelligent Booking Flow
- **Interactive Mapping**: Seamless pickup and destination selection via Leaflet/Google Maps.
- **Fare Recalculation**: Instant fare estimation based on destination changes.
- **Multi-Payment Selection**: Choose between Wallet, Cash, Bank Transfer, Voucher, or internal TaxiCoins.

### 3. Rewards & Gamification Hub
- **TaxiCoin Dashboard**: View current coin balance, daily streaks, and completion progress.
- **Trip Locks**: Visual indicators for feature unlocking (e.g., "Complete 3 trips to unlock spending").
- **Referral Tracking**: Real-time progress bars for User and Driver referral milestones.
- **Exchange System**: Redeem TaxiCoins for fiat currency equivalents (1000 TXC = $0.50).

### 4. Communication & Security
- **In-App VOIP Calling**: Fluent, high-fidelity voice calls with real-time ringing signaling and beep sounds.
- **Trip Security OTP**: Dedicated 4-digit code generation for secure trip finalization.
- **Interactive Audio Feedback**: Specialized "Coin Success" sounds for wallet top-ups, referral bonuses, and completions.

### 5. Multi-Payment & Settlement
- **Settlement Wizard**: Guided payment interface for Cash and Bank Transfer rides, ensuring passenger/driver synchronization.
- **Coin Augmentation**: Toggle preference to use coins as a secondary source to reduce cash or wallet payments.
- **E-Receipts**: Comprehensive trip details with breakdown of augmented coin discounts.

### 6. Profile & Security
- **Identity Management**: Real-time profile updates including avatar uploads.
- **Security Dashboard**: Password management and access control settings.
